# Transactions Overview

## Definition

Transactions represent financial movements in Poolaki and are divided into four types:

- **Incomes:** Money received into the account.

- **Expenses:** Money spent out of the account.

- **Savings**: also called contributions. Money moved from the general account into a specific savings goal.

- **Withdrawals:** Money moved from a savings goal back into the general account. A withdrawal is also created automatically when a goal with a positive balance is archived.

## Permissions and Collaboration

- All members of the workspace can view and create transactions.

- Only the member who created a transaction can edit or delete it.

- Creating a transaction notifies every other workspace member. Editing or deleting a transaction sends no notification.

- A personal workspace has no other members to notify.

## Transaction Details Visible

Each transaction entry displays the following information:

- Date
- Name / Description
- Category (income and expenses)
- Linked savings goal (contributions, withdrawals, and expenses paid from a goal)
- Value / Amount

## Creation, Editing, and Default Behavior

- Transactions can be created from the home page or the transactions page, and edited from the transactions page.

- Income and expense transactions require a category. Contributions and withdrawals require a goal; the Contribution category is applied automatically.

- Expenses are deducted from the general balance by default, unless explicitly associated with a savings goal. Only active goals without a deadline, or completed goals, can pay expenses.

- Expense transactions include an option to mark them as tax deductible.

## Where Transactions Appear and How to Filter Them

- **Transactions Page:** Lists all transactions or specific types. Users can sort items from newest to oldest and vice versa.

- **Filtering Options:** Transactions can be filtered by date range, transaction type, categories, savings goal, tax-deductible status, and creator. Text search matches the description, category name, and creator name.

- **Reports Page:** Shows income and expenses month by month for the selected year, plus savings. Detailed records remain on the transactions page.
